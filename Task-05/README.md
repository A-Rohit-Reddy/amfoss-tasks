## COMMANDS USED

	git clone <repository-url>: Clone a repository
	
	cd <directory>: Changes the current working directory to the specified path
	
	python -m venv <environment-name>: Create a virtual environment
	
	source <environment-name>/bin/activate: Activates the virtual environment
	
	pip install -r <file>: Install dependencies listed in the file
	
	python <script_name>: Run the python file	
	
	pip install <package-name>: Download the packages
	
	pip show <package-name>: Verify if the installation is complete
	
	python --version: Returns the current python version you are using
