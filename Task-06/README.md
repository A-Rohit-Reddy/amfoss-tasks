## COMMANDS USED

	flutter run: Builds and runs the Flutter project on a connected device, emulator, or simulator.
	
	flutter pub get: Fetches the dependencies listed in your pubspec.yaml file.
	
	flutter emulators --launch <device_name>: Launches a specific emulator by its name.
	
	flutter emulators: Lists all the available emulators on your system.
	
	flutter create <name>: Creates a new flutter project with the specified name.
	
	flutter doctor --android-licenses: Accepts the Android SDK licenses. This is necessary to set up Android development with flutter.
	
	flutter doctor: Checks your flutter environment to identify any missing dependencies or configurations.
