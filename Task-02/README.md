## Pixelated Problem Solver

This Python script extracts text from an image containing an arithmetic expression, sanitizes the text, and evaluates the expression. It leverages the Pillow library for image processing and pytesseract for Optical Character Recognition (OCR).

## My approach towards the task

I had to install the PIL (Pillow), re and pytesseract libraries in order to detect and extract the text from images to begin with. I took the help of google to know about the commands which are used to extract the text from the image and evaluate the expression. I faced a little difficulty in image-to-text conversion part. This was mainly because of the OCR misinterpreting the text, maybe due to an unclear image. I had to then use filter and sharpen function in order to make the image clear and evaluate the text. I also cross checked the extracted text to ensure correct reading of the image.
